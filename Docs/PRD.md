Questown Routine Game PRD

1. 제품 한 줄 정의

Questown은 사용자의 일상 컨텍스트가 시작되면 자동으로 열리는 루틴 타임어택 게임이다.

기존의 To-do 앱처럼 사용자가 해야 할 일을 목록으로 관리하는 것이 아니라,
기상 / 외출 / 이동 / 도착 / 취침 전 같은 특정 상황이 시작될 때 짧은 게임 세션을 열고,
그 세션을 수행한 결과가 매일의 건물과 월간 타운으로 시각화되는 구조를 목표로 한다.

⸻

2. 제품 비전

기존 방향
	•	할 일을 추가하고 체크한다
	•	체크한 결과가 건물 층수로 시각화된다
	•	하루 성과가 지붕과 리뷰로 마감된다

전환 방향
	•	사용자가 직접 계획표를 들여다보며 판단하는 앱이 아니다
	•	지금의 상황에 맞는 루틴 세션이 자동으로 제안되거나 시작되는 앱이다
	•	사용자는 목록을 관리하는 것이 아니라 짧은 플레이 세션을 수행한다
	•	하루의 세션 결과가 모여 건물이 되고, 건물이 모여 타운이 된다

핵심 차별점
	1.	컨텍스트 기반 실행: 시간/장소/상황에 따라 루틴이 열린다
	2.	게임 세션 중심 UX: 리스트보다 플레이 화면이 중심이다
	3.	감성 있는 성장 피드백: 수행 결과가 건물/오너먼트/타운으로 누적된다
	4.	AI 게임 마스터: 일정 관리자보다 난이도 조절과 돌발 퀘스트 제안 역할에 집중한다

⸻

3. 핵심 사용자 경험

사용자는 아침에 일어나면 앱에서 “모닝 루틴 시작” 세션을 받는다.
예를 들어 다음과 같은 흐름으로 플레이한다.
	•	잠자리 정리 1분
	•	샤워 15분
	•	영양제 먹기 5분
	•	옷 갈아입기 10분

각 단계는 타이머 기반으로 진행되며,
시간 내 수행 여부와 세션 전체의 흐름에 따라 점수와 콤보가 누적된다.
루틴이 끝나면 그날의 건물에 새로운 층이 생성된다.
여러 루틴을 수행하면 건물이 자라고,
하루 마감 시 수행 품질에 따라 지붕이 닫히며 하루가 완성된다.

장기적으로는 월간 캘린더 구조 위에,
계절감 있는 아이소메트릭 타운에 하루 단위 건물들이 배치되어
한 달의 생활 리듬이 예쁜 도시 풍경으로 누적되는 경험을 목표로 한다.

⸻

4. 북극성 정의

제품의 본질

Questown은 생산성 도구라기보다
생활 리듬을 플레이 가능한 형태로 바꾸는 게임형 루틴 시스템이다.

성공 기준

유저가 앱을 열고 “일정을 정리해야지”라고 느끼는 것이 아니라,
**“지금 내 상황에 맞는 한 판을 시작하자”**라고 느껴야 한다.

정서적 목표
	•	압박보다는 흐름
	•	실패보다는 부분 성공
	•	자책보다는 성장 흔적
	•	체크리스트보다 플레이 감각

⸻

5. 제품 원칙

5.1 계획보다 실행 중심

사용자는 많은 설정과 계획을 하지 않아도 바로 플레이할 수 있어야 한다.

5.2 짧고 자주 플레이

한 세션은 보통 3~15분 내에서 끝나는 것이 이상적이다.
긴 루틴도 내부적으로는 짧은 스테이지처럼 느껴져야 한다.

5.3 피드백은 즉시, 결과는 누적

스텝 완료 시 즉각적인 피드백을 주고,
세션 결과는 건물과 타운에 장기적으로 반영한다.

5.4 실패를 벌주지 않는다

실패한 날에도 도시가 무너지지 않아야 한다.
대신 흐린 날씨, 미완성 지붕, 부분 장식 등으로 부드럽게 표현한다.

5.5 표면은 단순하게, 내부는 깊게

유저가 보는 UI는 매우 단순해야 하지만,
내부적으로는 루틴 설계, 점수 계산, AI 제안, 도시 성장 규칙이 정교하게 돌아갈 수 있다.

⸻

6. 핵심 게임 루프

상위 루프
	1.	트리거 발생
	2.	루틴 세션 시작
	3.	스텝 수행
	4.	점수 및 콤보 정산
	5.	건물 층 생성
	6.	하루 종료 시 지붕 완성
	7.	리뷰 후 타운에 반영

기존 구조와의 차이

기존에는 “퀘스트 추가 → 완료 체크 → 건물 시각화”였다면,
이제는 “상황 시작 → 세션 플레이 → 결과 반영”으로 바뀐다.

즉, 사용자 행동의 최소 단위가 개별 todo가 아니라
세션 단위의 플레이 경험이 된다.

⸻

7. 루틴 시스템 설계

7.1 루틴의 정의

루틴은 단순한 반복 todo가 아니라,
특정 상황에서 실행되는 게임 스테이지다.

각 루틴은 다음 정보를 가진다.
	•	루틴 이름
	•	발동 조건
	•	예상 총 소요 시간
	•	스텝 목록
	•	성공 조건
	•	보너스 조건
	•	시각 테마
	•	보상 타입

예시 루틴 카테고리
	•	Morning Reset
	•	Leave Home Sprint
	•	Commute Focus
	•	Arrival Setup
	•	Night Shutdown
	•	Weekend Reset

⸻

7.2 루틴 발동 조건

루틴은 아래 방식으로 시작될 수 있다.

시간 기반
	•	기상 직후
	•	점심 전
	•	취침 전
	•	특정 시각대

위치 기반
	•	집을 떠날 때
	•	지하철역 도착 시
	•	직장 도착 시
	•	헬스장 도착 시

수동 시작
	•	유저가 홈 화면에서 직접 시작
	•	알림이나 위젯을 눌러 시작

추천 시작
	•	AI가 최근 패턴을 바탕으로 시작 پیشنهاد
	•	예: “지금 Night Shutdown을 시작하면 streak를 유지할 수 있어요”

⸻

7.3 스텝 구조

루틴은 3~6개의 짧은 스텝으로 구성한다.

각 스텝은 다음 속성을 가진다.
	•	이름
	•	권장 시간
	•	최소 성공 기준
	•	난이도
	•	성격 태그
	•	완료 연출 타입

예시

Morning Reset
	•	침구 정리 1분
	•	세수/샤워 12분
	•	영양제 먹기 2분
	•	옷 갈아입기 5분
	•	가방 챙기기 3분

스텝 수가 너무 많으면 피로하므로,
최대한 “행동 덩어리” 단위로 묶는 것이 중요하다.

⸻

8. 점수 시스템

점수는 단순 속도 경쟁이 아니라
생활 리듬을 유지한 것 자체를 보상해야 한다.

8.1 기본 점수
	•	스텝 완료 점수
	•	루틴 완주 보너스
	•	하루 첫 세션 보너스

8.2 타이밍 점수
	•	권장 시간 내 완료: Time Bonus
	•	매우 안정적으로 완료: Perfect Pace Bonus
	•	시간 초과지만 완료: Reduced Bonus

8.3 흐름 점수
	•	연속 성공: Combo
	•	skip 없이 완주: Clean Run
	•	pause 없이 완주: Focus Bonus
	•	특정 시간대 연속 성공: Streak Bonus

8.4 감정 보호 장치
	•	시간 초과를 곧바로 실패 처리하지 않는다
	•	완주만 해도 최소 보상은 준다
	•	1회 정도의 초과는 Grace 판정으로 흡수할 수 있다
	•	최근 성공률이 낮아지면 AI가 권장 시간을 완화한다

8.5 결과 등급 예시
	•	Perfect
	•	Great
	•	Clear
	•	Partial

유저는 “실패했다”보다
“오늘은 Partial이지만 그래도 이어갔다”라고 느껴야 한다.

⸻

9. 콤보와 스트릭

9.1 세션 콤보

같은 루틴 안에서 스텝을 연속으로 수행하면 쌓인다.
	•	빠른 리듬 유지
	•	skip 없는 흐름
	•	중단 없는 몰입

세션 콤보는 즉시 피드백용이다.

9.2 루틴 스트릭

같은 루틴을 여러 날 연속 수행하면 쌓인다.
	•	Morning streak
	•	Night streak
	•	Work arrival streak

루틴 스트릭은 건물의 장식과 디테일을 강화한다.

9.3 메타 스트릭

하루 전체 루틴 수행 품질이 누적되면 월간 메타 보상으로 이어진다.
	•	특별 랜드마크
	•	계절 장식 강화
	•	월간 배경 변화
	•	타운 내 특수 오브젝트 등장

⸻

10. 건물 성장 시스템

기존의 “퀘스트 1개 = 1층” 규칙은 루틴 게임 구조로 바뀌며,
이제는 루틴 1회 완주 = 건물 1층 생성이 기본이 된다.

10.1 기본 규칙
	•	루틴 1회 성공 = 건물 1층 생성
	•	루틴 내부 수행 품질 = 층의 디테일 결정
	•	하루 전체 수행률 = 지붕 타입 결정
	•	streak = 오너먼트/조명/장식 강화
	•	surprise quest 성공 = 특수 장식 추가

10.2 층 스타일 매핑

루틴의 성격에 따라 층 디자인을 다르게 만든다.

Morning
	•	밝은 창문
	•	화분
	•	베란다
	•	아침 햇빛 톤

Commute
	•	간판
	•	표지판
	•	도시형 패널
	•	이동감 있는 디테일

Work / Arrival
	•	오피스 유리창
	•	배지
	•	깃발
	•	정돈된 구조

Night
	•	따뜻한 조명
	•	침실 실루엣
	•	별 장식
	•	조용한 야간 톤

Health / Care
	•	식물
	•	웰니스 소품
	•	테라스
	•	자연 친화적 디테일

⸻

10.3 지붕 시스템

하루의 루틴 세션이 끝나면 건물 위에 지붕이 닫히며 하루를 마감한다.

지붕 타입 예시
	•	Low: 일부 루틴만 수행
	•	Mid: 주요 루틴 수행
	•	High: 높은 완성도와 흐름 유지
	•	Gold Roof: 매우 높은 수행 품질 + 보너스 조건 달성

지붕은 단순 완료율뿐 아니라,
그날의 흐름과 리듬의 질을 반영하는 메타 표시가 된다.

⸻

11. 타운 시스템

11.1 기본 구조

타운은 해당 월의 캘린더를 기반으로 구성된다.
각 날짜는 하나의 plot이며,
그 위에 그날의 건물이 생성된다.

즉,
	•	1일 = 1 plot
	•	하루의 루틴 수행 결과 = 해당 plot의 건물
	•	한 달 = 건물들이 모인 타운

11.2 시각 방향

최종 목표는
심플하고 귀여운 아이소메트릭 뷰의 3D 타운이다.

원하는 인상은 다음과 같다.
	•	부드럽고 포근한 톤
	•	계절감이 드러나는 배경
	•	복잡하지 않은 심볼릭 건물 형태
	•	작은 장식들이 쌓이는 즐거움
	•	전체를 한눈에 보고 싶은 예쁜 월드 감성

11.3 MVP 구현 방향

MVP에서는 실제 3D보다
2.5D 가짜 아이소메트릭 방식으로 구현한다.

방식
	•	달력 구조 = 타일 기반 플롯
	•	건물 = 레이어드 스프라이트 스택
	•	그림자, depth sorting, 경사 배치로 입체감 표현
	•	카메라는 고정
	•	확대/축소는 최소화

이유
	•	구현 부담 감소
	•	아트 방향 테스트 용이
	•	모바일 퍼포먼스 안정
	•	게임 룰 검증이 먼저 가능

11.4 최종 확장 요소
	•	계절별 맵 테마
	•	낮/밤 변화
	•	날씨 연출
	•	랜드마크
	•	작은 NPC
	•	월간 파노라마 뷰
	•	streak 전용 장식물

⸻

12. AI의 역할

AI는 생산성 코치가 아니라,
게임 마스터 / 라이브 이벤트 디렉터 역할을 맡는다.

12.1 루틴 설계 보조
	•	사용자의 생활 패턴을 보고 루틴 초안 제안
	•	각 스텝 시간 자동 추천
	•	너무 긴 루틴은 분리 제안
	•	루틴 설명을 게임적으로 표현

12.2 난이도 조절
	•	최근 성공률이 낮으면 루틴 시간을 완화
	•	너무 쉬우면 Perfect 조건을 소폭 강화
	•	평일/주말/피곤한 날에 따라 제안 강도를 조절
	•	skip이 잦은 스텝은 재배치 제안

12.3 돌발 퀘스트 생성

하루의 컨텍스트에 맞는 작은 미션을 제안한다.

예시
	•	점심 전 물 500ml 마시기
	•	퇴근 전 책 5쪽 읽기
	•	귀가 후 책상 위 물건 3개 정리하기
	•	오후 3시 전에 3분 스트레칭 하기

돌발 퀘스트는 핵심 루틴을 방해하지 않으면서,
하루를 단조롭지 않게 만드는 라이브 이벤트 역할을 한다.

12.4 리뷰 내레이션
	•	오늘의 흐름 요약
	•	어떤 루틴이 안정적이었는지
	•	어디서 끊겼는지
	•	내일 어떤 루틴을 가볍게 조정하면 좋을지

12.5 월드 빌딩
	•	건물 이름 생성
	•	오너먼트 이름 부여
	•	월간 테마 제안
	•	특별 이벤트명 생성

⸻

13. UX 구조

이 제품의 중심은 리스트 화면이 아니라 세션 화면이다.

13.1 홈 화면

홈은 최대한 단순해야 한다.

보여줄 정보
	•	지금 시작 가능한 루틴 1개
	•	다음 예정 루틴 1개
	•	오늘의 건물 진행률
	•	현재 streak / combo 요약
	•	돌발 퀘스트 1개 (선택적)

홈의 역할
	•	계획 보드가 아니다
	•	지금 플레이할 수 있는 다음 행동을 보여주는 런처다

13.2 루틴 세션 화면

루틴 시작 시 풀스크린에 가까운 몰입형 화면으로 전환한다.

핵심 요소
	•	현재 스텝 이름
	•	남은 시간
	•	전체 세션 진행률
	•	다음 스텝 미리보기
	•	완료 / pause / skip 버튼
	•	현재 combo
	•	작은 캐릭터/건물 실루엣 반응

정서 목표
	•	정보 과다 금지
	•	즉시 행동 가능
	•	게임처럼 반응적
	•	다음 행동이 자연스럽게 이어짐

13.3 세션 결과 화면

루틴 종료 후 짧은 정산 화면을 보여준다.

포함 요소
	•	결과 등급
	•	획득 점수
	•	combo 반영
	•	새로운 층 생성 연출
	•	오너먼트 획득 여부
	•	짧은 AI 코멘트

이 화면은 2~4초 내에 빠르게 전달되어야 하며,
유저에게 즉각적 만족감을 줘야 한다.

13.4 하루 리뷰 화면

하루 종료 시 보여주는 전체 정산 화면이다.

포함 요소
	•	오늘 완성된 건물
	•	지붕 타입
	•	수행한 루틴 목록
	•	streak 변화
	•	돌발 퀘스트 결과
	•	AI 하루 요약
	•	내일 추천 루틴

15. 기술 방향 제안

15.1 MVP 단계

우선은 현재 웹 기반 구조를 활용해
다음 요소를 먼저 검증한다.
	•	루틴 세션 UX
	•	타이머 흐름
	•	점수 및 콤보 시스템
	•	건물 층 생성 룰
	•	하루 리뷰 연출
	•	2.5D 타운 표현 가능성

15.2 제품화 단계

실제 서비스화 시에는 위치/알림/백그라운드 동작이 중요하므로,
모바일 네이티브 셸 전환을 고려한다.

추천 방향
	•	React Native / Expo 기반 앱 셸
	•	알림, 백그라운드 태스크, 위치 트리거 대응
	•	계정/동기화/멀티디바이스 확장

15.3 Godot의 위치

Godot는 장기적으로 타운 렌더링이나 미니게임성 강화에 매력적일 수 있으나,
초기 MVP의 핵심은 예쁜 3D가 아니라 루틴 세션과 트리거 경험 검증이다.

따라서 초기 단계에서는
Godot보다 현재 프론트 또는 모바일 앱 셸 기반으로 핵심 루프를 먼저 검증하는 것이 더 합리적이다.

19. 최종 정리

Questown은 더 이상 “할 일을 시각화하는 앱”이 아니라,
일상의 특정 순간을 짧은 루틴 게임 세션으로 바꾸고,
그 성과를 건물과 타운으로 축적하는 생활 게임이 되어야 한다.

이 방향의 핵심은 다음 세 가지다.
	1.	루틴 세션 중심 구조
	2.	건물과 타운으로 누적되는 감성 피드백
	3.	AI 게임 마스터를 통한 난이도 조절과 돌발 퀘스트 생성

즉,
사용자는 하루를 관리하는 것이 아니라
하루를 플레이하게 된다.
